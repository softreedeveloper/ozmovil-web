# ozmobil-web

Landing de OzMobile — reparación de celulares y tablets.

```
npm install
npm run dev     # http://localhost:7005
npm run build
```

Todos los datos del negocio (teléfono, WhatsApp, ubicación, horario, redes, dominio) se editan en **`src/utils/site-config.js`**. Ver `CLAUDE.md` para la arquitectura.
